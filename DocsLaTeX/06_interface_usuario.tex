\section{Introdução}
Este documento apresenta o projeto de interface com o usuário do sistema Kanban, representado por meio de storyboards e wireframes (esboços simples de tela).

\section{Storyboards e Cenários de Uso}
Cada storyboard no link a seguir descreve um cenário de uso do sistema de software por meio de uma sequência de telas (wireframes).

Como os cenários de uso do sistema são numerosos, o grupo reuniu os storyboards em um projeto usando a ferramenta Figma, cujo link pode ser acessado abaixo:

\textbf{Link para acesso aos storyboards com wireframes: https://www.figma.com/design/wHSHX4lseipwvFJh8jGIZM/ESW?node-id=0-1&t=ZNp3SfBMQUBAk2ws-1} 

Pretende-se que os cenários sejam utilizados para gerar testes positivos de funcionalidades no vídeo com teste de sistema, além de servir como guia na implementação da interface.
